## 一、决策树是什么

决策树是一种**树形结构的监督学习模型**，既能做分类也能做回归。它通过一系列「if-else」判断把样本从根节点逐步引导到叶子节点，叶子节点给出预测结果。

**结构组成：**

- **根节点（root）**：包含全部样本，是第一个判断。
- **内部节点（internal node）**：一次特征判断（一个「问题」）。
- **叶子节点（leaf）**：最终的类别（分类）或数值（回归）。
- **分支（branch）**：判断的某个结果对应的走向。

**核心思想：** 每一步都选一个特征做判断，使得划分后子集尽可能「纯」（同类聚在一起）。本质是一种**贪心 + 递归**的划分过程。

**基本流程（递归建树）：**

1. 计算当前节点所有候选特征的划分优劣（用熵/基尼等尺子）。
2. 选出最优特征作为当前判断条件，划分成若干子集。
3. 对每个子集递归执行 1–2。
4. 满足停止条件时生成叶子节点（返回类别/数值）。

**停止条件（任一满足即停）：**

- 当前节点所有样本属于同一类别（已经纯了）。
- 没有可用特征了，或所有样本在剩余特征上取值都相同。
- 满足预剪枝条件（深度、样本数、增益阈值等）。

## 二、衡量标准：熵

### 2.1 直觉

**熵（Entropy）衡量一堆数据「有多乱 / 类别有多不确定」。** 通俗理解就是"物体内部的混乱程度"：杂货市场什么都有，很乱（熵高）；专卖店只卖一个牌子，很稳定（熵低）。

也可以理解为「平均惊讶度」：抽一个样本，结果越难猜，熵越高。

### 2.2 公式

$$H(X) = -\sum_{i=1}^{n} p_i \log_2 p_i$$

- $p_i$：第 $i$ 类样本占的比例。
- $-\log_2 p_i$：某一类的**信息量（自信息）**，这一类占比越小，值越大（越"惊讶"）。
- 整体是**按比例加权的平均**：熵 = 全体样本"我这一类有多小"的平均分。

**易混点：**

- $-\log_2 p_i$ 是**单个类别**的信息量，是中间产物。
- $\sum p_i(-\log_2 p_i)$ 才是**整个集合**的熵，是最终答案。单个类别没有熵。
- 公式里的 $p_i$ 本质就是"除以样本总数"——`求平均`这一步已经折进权重里了，看到公式不需要再额外除。

### 2.3 关键性质

- $p=0$ 或 $p=1$ 时（二分类），$H=0$，完全没有不确定性（最纯）。约定 $0 \cdot \log 0 = 0$。
- $p=0.5$ 时（二分类），$H=1$，不确定性最大（最乱）。这是**二分类**的上限。
- **一般地，$n$ 个类别且均分时，熵取最大值 $\log_2 n$**（2类→1，4类→2，8类→3）。所以类别多的集合熵可以远大于 1。
- 二分类熵曲线是**倒 U 形**，中间（0.5）最高，两端（0/1）为 0。
- log 的底数不影响特征选择：底为 2 单位是 bit，底为 e 单位是 nat，换底只是整体乘一个常数，比较大小的排序不变。

### 2.4 计算示例

- A 集合 `[1×8, 2×2]`：$H = 0.8\times(-\log_2 0.8) + 0.2\times(-\log_2 0.2) = 0.72$
- B 集合 `[1,2,3,4,5,6,7,8,9,1]`（9 类，1 出现 2 次）：$H = 0.2\times2.32 + 8\times(0.1\times3.32) = 3.12$

A 只有 2 类且集中，熵小（更纯）；B 几乎人人自成一类，熵大（更乱）。B 的 3.12 已接近 9 类上限 $\log_2 9 \approx 3.17$。

## 三、信息增益与特征选择

### 3.1 条件熵

按特征 $a$ 划分后的"剩余乱度"，是各子集熵的**按样本数加权平均**：

$$H(D \mid a) = \sum_{v} \frac{|D_v|}{|D|} H(D_v)$$

权重 $\frac{|D_v|}{|D|}$ 和熵内部的 $p_i$ 同理：子集样本越多，说话越响。

### 3.2 信息增益（Information Gain）

$$\text{Gain}(D, a) = \underbrace{H(D)}_{\text{切之前}} - \underbrace{H(D \mid a)}_{\text{切之后的加权熵}}$$

**含义：** 用特征 $a$ 划分后，类别不确定性**减少的程度**。增益越大，这个特征越有区分力。

**关键性质：**

- 信息增益 **永远 ≥ 0**（切一刀只会变纯或不变，不会更乱）。
- 增益 = 0 说明该特征和类别无关（切了白切）。

**建树时：** 把所有还没用过的特征各切一遍，谁增益最大就选谁作为当前节点。

### 3.3 三步走（回顾）

1. 算父节点熵 $H(D)$。
2. 按某特征切开，各子节点算熵，**按样本占比加权求和** 得 $H(D\mid a)$。
3. 二者相减 = 信息增益。

## 四、三大算法：ID3 / C4.5 / CART

| 算法 | 划分标准 | 支持任务 | 特征类型 | 树结构 | 备注 |
|---|---|---|---|---|---|
| **ID3** | 信息增益 | 分类 | 离散 | 多叉 | 偏爱多值特征，不支持连续值/缺失值/剪枝 |
| **C4.5** | 信息增益率 | 分类 | 离散+连续 | 多叉 | 修正 ID3 缺陷，支持连续值、缺失值、剪枝 |
| **CART** | 基尼系数（分类）/ 平方误差（回归） | 分类+回归 | 离散+连续 | **二叉** | sklearn 默认，工业界主流 |

### 4.1 ID3 的致命缺陷

**信息增益偏爱"取值多"的特征。** 取值越多 → 切得越碎 → 每个子集越容易显得纯 → 增益虚高。

**极端例子（编号陷阱）：** 拿「ID 编号」这种每人一个值的特征切分，切出 N 个只含 1 个样本的桶，每个桶熵为 0，加权熵为 0，信息增益直接拉满，完胜所有正经特征。但这样的树只是**背下了训练集**，遇到没见过的新编号完全失效——严重过拟合。

**ID3 其它缺点：**

- 只能处理离散特征。
- 不能处理缺失值。
- 没有剪枝，容易过拟合。

### 4.2 C4.5：信息增益率

用**特征自身的分裂熵**当分母，惩罚取值多的特征：

$$\text{GainRatio}(D,a) = \frac{\text{Gain}(D,a)}{IV(a)}, \qquad IV(a) = -\sum_v \frac{|D_v|}{|D|}\log_2\frac{|D_v|}{|D|}$$

- $IV(a)$（Intrinsic Value / 分裂信息）**只看特征自己的取值分布，不看类别标签**。
- 特征取值越多、越分散 → $IV(a)$ 越大 → 增益率被压得越低。
- 例：编号列 10 个值，$IV = \log_2 10 = 3.32$，把满分增益直接除小；正经二值特征 $IV$ 小，几乎不受影响。

**注意：** 增益率反过来会**偏爱取值少的特征**。所以 C4.5 实际用的是**启发式**：先从候选中挑出信息增益高于平均水平的特征，再从中选增益率最高的。

### 4.3 CART

- 分类用**基尼系数**，回归用**平方误差**。
- 只做**二叉划分**（连值也是"≤某值 / >某值"，离散多值也拆成"是某值 / 不是某值"），结构上避免了多值爆炸。
- 支持连续值、缺失值、剪枝，可做回归。是 sklearn 的默认实现。

## 五、基尼系数

### 5.1 公式与直觉

$$\text{Gini}(p) = \sum_{k=1}^{K} p_k(1-p_k) = 1 - \sum_{k=1}^{K} p_k^2$$

**白话含义：** 从样本中**随机抓两个，它俩类别不一样的概率**。

- 抓两个都是类 $k$ 的概率是 $p_k^2$，"抓到同类"总概率 $\sum p_k^2$，那"不同类" = $1-\sum p_k^2$。
- 全是一类 → Gini = 0（最纯）；二分类五五开 → Gini = 0.5（最乱）。

### 5.2 基尼增益（划分依据）

和信息增益类比，划分后取加权基尼：

$$\text{Gini\_index}(D,a) = \sum_v \frac{|D_v|}{|D|}\text{Gini}(D_v)$$

CART 选使**划分后基尼指数最小**的特征（等价于基尼下降最多）。

### 5.3 基尼 vs 熵

- 二分类下两者曲线**形状几乎一致**（都是倒 U，中间最乱），选出的特征绝大多数时候相同。
- 熵最大值 1，基尼最大值 0.5（二分类）。
- **基尼不用算 log，计算更快**，所以 CART / sklearn 默认用它。
- 熵对不纯度惩罚略重（曲线更"鼓"），倾向生成更平衡的树；差别在实践中通常很小。

## 六、连续值处理

连续特征（如收入 60K、95K、125K）不能给每个值开分支（否则退化成编号陷阱）。做法是**二分离散化**：

**三步：**

1. **排序**：把该特征所有取值从小到大排列。
2. **取候选切点**：相邻两值的**中点**作为候选。$n$ 个不同取值有 $n-1$ 个候选切点。
3. **逐个评估**：每个候选切点切成「≤t」「>t」两半，各算一次信息增益/基尼下降，**选增益最大的切点**。

**要点：**

- 这本质是「**离散化**」：连续的数值被切成「高/低」两个离散类别。
- 属于**贪心算法**：每层只挑当前最优切点，不保证全局最优（找全局最优树是 NP 难）。
- 连续特征可以**在一条路径上被多次使用**（不同切点），离散特征在 ID3/C4.5 里用过一次就不再用。

**示例（查税表收入）：** 排序后作弊者集中在 85/90/95。切在 97.5（左 6 人 3:3、右 4 人全诚实）增益 0.281，优于切在 80 的 0.191，故选 97.5。

## 七、缺失值处理

C4.5 / CART 都能处理缺失值，核心两个问题：

**（1）如何在有缺失的情况下选划分特征？**
用**无缺失样本**计算信息增益，再乘以一个权重 $\rho$（无缺失样本所占比例），对该特征的增益打折。

**（2）某样本在划分特征上缺失，划到哪个分支？**
把该样本**按比例同时划入所有子节点**（带一个权重），权重等于各分支无缺失样本的占比。预测时再对结果加权。

（CART 还有一种做法叫**代理划分 / surrogate split**：找一个和主划分特征高度相关的备用特征，缺失时用备用特征来分。）

## 八、剪枝

决策树天生停不下来——为了把训练集每个"怪人"都分对，会长出学习噪声的枝杈，导致**过拟合**（训练集准确率很高，测试集反而下降）。剪枝就是治过拟合。

### 8.1 预剪枝（Pre-pruning）

**边长边拦**：在生长过程中提前设限，不满足条件就停止分裂。常见限制：

- 最大深度（`max_depth`）
- 叶子节点最少样本数（`min_samples_leaf`）
- 内部节点最少样本数（`min_samples_split`）
- 最大叶子数（`max_leaf_nodes`）
- 最小信息增益/不纯度下降（`min_impurity_decrease`）

**优点：** 简单、快、树小、计算开销低（很多分支根本不展开）。工业界最常用。
**缺点：** 有"短视"风险——某次分裂当前增益不大，但后续可能有用，预剪枝会把它连带的好分支一起砍掉，可能**欠拟合**。

### 8.2 后剪枝（Post-pruning）

**先长满，再回砍**：先生成完整的树，然后自底向上评估每个子树，用某个尺子决定是否把它并成一个叶子。

**代价复杂度剪枝（Cost-Complexity Pruning, CCP，CART 用）：**

$$C_\alpha(T) = C(T) + \alpha \cdot |T_{leaf}|$$

- $C(T)$：树在数据上的**误差/不纯度**（树越复杂越小）。
- $|T_{leaf}|$：**叶子个数**，代表复杂度。
- $\alpha$：**罚款单价**，越大越逼树精简。

白话：**总代价 = 预测有多差 + 树有多啰嗦 × 罚款单价**。逐个子树比较"剪 vs 不剪"的总代价，哪个小取哪个。$\alpha$ 越大剪得越狠（sklearn 参数 `ccp_alpha`）。

**优点：** 通常泛化能力比预剪枝好（保留了更多有用结构），欠拟合风险小。
**缺点：** 要先长满整棵树再回剪，**计算开销大**。

> 对比记忆：预剪枝像"边写边删，可能删过头（欠拟合）、但快"；后剪枝像"先写完再精修，效果好、但慢"。

## 九、回归树

CART 也能做回归。差别只在**衡量标准**和**叶子输出**：

- **划分标准**：不用熵/基尼，改用**平方误差（MSE）**。选使划分后两个子集平方误差之和最小的切点。
  $$\min_{a,t}\left[\min_{c_1}\sum_{x_i\in D_1}(y_i-c_1)^2 + \min_{c_2}\sum_{x_i\in D_2}(y_i-c_2)^2\right]$$
- **叶子输出**：叶子内所有样本目标值的**均值**（分类是"多数投票"，回归是"取平均"）。
- 预测就是把样本导到某个叶子，输出该叶子的均值。

## 十、优缺点

**优点：**

- 可解释性强，规则直观（if-else），可可视化。
- 不需要特征归一化/标准化（基于阈值划分，对量纲不敏感）。
- 能同时处理离散和连续特征。
- 训练/预测速度快，对特征缺失/异常值相对不敏感。
- 能自动做特征选择（重要特征在上层）。

**缺点：**

- **容易过拟合**（尤其不剪枝时）。
- **不稳定**：数据轻微变化可能导致树结构大变（高方差）。
- 是**贪心**算法，得到的是局部最优而非全局最优树。
- 决策边界是**轴平行**的（一次只看一个特征），对角线关系需要很多层才能逼近。
- 对**类别不平衡**敏感，容易偏向多数类。
- 单棵树预测能力有限 → 实践中常用**集成方法**（随机森林、GBDT、XGBoost）来提升。

## 十一、常见面试问答速记

**Q：决策树如何选择划分特征？**
A：计算每个候选特征划分后的纯度提升（信息增益 / 信息增益率 / 基尼下降），选提升最大的。

**Q：信息增益和信息增益率的区别？为什么要有增益率？**
A：信息增益偏爱取值多的特征（极端如 ID 列会过拟合）；增益率用特征自身分裂熵做分母惩罚多值特征。但增益率又偏爱取值少的，所以 C4.5 用启发式：先筛增益高于平均的，再取增益率最高的。

**Q：基尼系数和熵怎么选？**
A：形状几乎一样，选出的特征基本相同。基尼不用算 log 更快，是 CART/sklearn 默认；熵略微惩罚更重。

**Q：ID3、C4.5、CART 的核心区别？**
A：见[第四节表格](#四三大算法id3--c45--cart)。标准：增益 / 增益率 / 基尼；结构：多叉 / 多叉 / 二叉；任务：分类 / 分类 / 分类+回归。

**Q：连续值怎么处理？**
A：排序 → 取相邻中点为候选切点 → 逐个算增益选最优 → 二分离散化。

**Q：决策树为什么会过拟合？怎么防？**
A：会无限迁就训练集噪声。防：预剪枝（限深度/样本数/增益）、后剪枝（代价复杂度）、集成（随机森林）。

**Q：预剪枝 vs 后剪枝？**
A：预剪枝边长边拦，快但可能欠拟合；后剪枝先长满再回砍，慢但泛化通常更好。

**Q：决策树需要归一化吗？**
A：不需要。基于阈值划分，对特征量纲不敏感。

**Q：决策树能处理缺失值吗？**
A：C4.5/CART 可以。选特征时用无缺失样本算增益并按比例打折；样本缺失时按权重划入多个分支（CART 还可用代理划分）。

**Q：为什么决策树是高方差模型？**
A：贪心 + 层层依赖，训练数据小变动会改变上层划分，进而级联改变整棵树 → 随机森林用 bagging 降方差。

**Q：为什么随机森林/GBDT 比单棵树好？**
A：单树高方差易过拟合；随机森林用 bagging + 特征随机降方差；GBDT 用 boosting 逐步拟合残差降偏差。

**Q：决策树的决策边界是什么形状？**
A：轴平行的矩形分区（每次只对一个特征设阈值）。

## 十二、sklearn 关键参数

`sklearn.tree.DecisionTreeClassifier / DecisionTreeRegressor`

| 参数 | 作用 | 调优方向 |
|---|---|---|
| `criterion` | 划分标准：`gini`（默认）/`entropy`/`log_loss`；回归 `squared_error` 等 | 一般用默认 |
| `max_depth` | 最大深度 | 越小越防过拟合，常调 |
| `min_samples_split` | 内部节点再分裂所需最少样本 | 增大防过拟合 |
| `min_samples_leaf` | 叶子最少样本数 | 增大防过拟合，常调 |
| `max_leaf_nodes` | 最大叶子数 | 限制树规模 |
| `min_impurity_decrease` | 最小不纯度下降阈值 | 增大防过拟合 |
| `max_features` | 每次划分考虑的最大特征数 | 降低方差 |
| `ccp_alpha` | 代价复杂度剪枝的 α | 增大剪得更狠 |
| `class_weight` | 类别权重 | 处理类别不平衡 |

**防过拟合优先调：** `max_depth`、`min_samples_leaf`、`ccp_alpha`。
